# I4 — Client: Apple TV native focus and Menu

Status: done (S1 code + build, S2 probe + live on the Apple TV 4K sim; worktree ../streamarr-i4, branch round-i/i4)

## Intent
Close the Apple TV gaps I3/F7/F8 left for native work: initial focus in the presented Versions/About sheets, Menu one
level at a time (sheet, library grid → chip, non-Start tab → Start, player overlay), focus after the player
("Zurück zu den Details"), the top tab bar hiding while Settings scrolls, plus the JS-only leftovers (last Versions card
glow, deep link over a detail) and the one-time VLCKit-on-tvOS check. Native code goes into one Expo module
(`client/modules/tv-native`), so it survives `expo prebuild`; nothing is hand-edited in `ios/`. The tvOS build runs in a
separate git worktree so the iOS dev build in the main tree stays untouched.

Research (root causes with file/line references, fix designs, tests, live proofs, build plan):
`docs/client/runs/driver/I4-research.md`.

### Summary
The I4 design holds up: UIKit work runs on main (`runOnQueue(.main)`, `install` dispatched), one recogniser per window
(weak table, no duplicates or leaks), the module is tvOS-only at both the podspec and JS level, the claim stack and its
safety net behave as documented, and the core JS rules are guarded by tests (10/16 mutations caught). Two code bugs:
`StackPop.find` matches the root stack before the tab stacks (a link while the player is open pops the player), and a
superseded focus request triggers the JS fallback on the stale target. Main risks: the native Menu mode survives a JS
reload (Menu dead at Start), the library claim stays `always` when focus leaves to the tab bar via the sort control, a
non-animated transition coordinator never runs the request, and the focus retry can fight the user outside a
`TVFocusHost`. Quality: probe code ships in release (`debugFocus`, `observe`, `__tvNative`), an unused
`firstDescendant`, two multi-line comments; screen-level wiring (player claim, `requestReturnFocus`, Sheet `native`
claim, library `isFocused`) is untested.
