# M4.1 — Browse: home, search, details, versions

Status: done

## Summary
Browse screens of the core loop, built in the M2.4 shells, on Google TV, Android phone and web (desktop + 1024x1366):
- **Data** (`src/browse/queries.ts`): account-scoped hooks for discover (persisted), continue watching
  (`watch/resume`), next up, movie/series/season details, search (type filter), versions with this
  device's `media-caps` profile as prediction hints (`player/device-profile.ts`, measured once per run),
  mark played/unplayed; watch-dependent queries are invalidated after marking and after a playback stops.
- **Home**: phone/tablet/web hero of the top pick (logo, rating, Play/Resume + More info), TV fixed hero
  above the rows that follows the focused card (backdrop + logo + facts + synopsis + progress, settles
  250 ms after the last D-pad move via `FeaturedStore`, no re-render of the rows); rows: continue watching
  (landscape, progress, OK resumes, long press opens the title), next up (minus items already in continue
  watching), discover rows; skeletons, empty state, full error state or a warning banner with retry when
  cached rows exist.
- **Search**: debounced, All/Movies/Series filter (radio group), result cards with type + year, recent
  searches per account in MMKV `streamarr.recent.<accountId>` (added on submit/open, long press removes,
  Clear; deleted with the account cache), TV keyboard via the M2.3 TextField.
- **Movie detail**: hero with logo (title fallback), year/runtime/genres, certification badge, watched badge,
  resume progress + time left, Play/Resume, Start over, Versions, Mark watched/unwatched (toast), Versions
  section (recommended or last played version with predicted method and count).
- **Series detail**: next-episode CTA (Play/Resume/Play next Sx, Ey by `nextEpisode.reason`) with progress,
  watched count, mark series watched/unwatched (server expands), season picker with played/total, inline
  episode list (played mark, progress, unaired dimmed, per-row versions + watched toggle, 2 columns on wide
  web); the season route reuses the list.
- **Version picker** (`Sheet` wide side panel on TV/tablet/web, bottom sheet on phones): cards with
  recommended/last played/instant/preparing/verified/degraded badges, headline (4K/HDR/source), codecs + bit
  depth, audio + channels + Atmos, audio/subtitle languages (own de/en names; Hermes lacks
  Intl.DisplayNames), edition/proper/repack/season pack/group, size, ≈ bitrate, age, predicted method +
  localized reasons, raw release name; choosing one plays it.
- **Play route** `/play/new?workId&releaseId&start&title`: starts the playback through the M3.1 path
  (`PlayerSession` with `startSeconds`, lab diagnostics off, expo-video/VLC/web engine), shows the server
  start states, errors with retry/back, minimal close/pause; stops + reports on exit. M4.2 replaces the UI.
- ErrorState now uses `describeError` (age-gate reason, other device). de + en for every new string.

## Decisions
- Continue watching cards resume directly (TV and phone convention); the title opens on long press.
- TV home: hero is a fixed region above a scrolling rows area (Google TV style) instead of a scrolled hero,
  so it stays visible while it follows focus; backdrop fades behind the page.
- Logos are fetched from the (cached) detail query of the featured title: `CatalogItemDto` has no logo.
- Versions are fetched on detail open (server-cached, needed for the summary); predictions use the first
  non-VLC engine of the device profile (native/web), so they mean "plays natively on this device".
- Episode lists live on the series page (season picker switches inline); only the standalone season page
  gives episodes preferred TV focus (otherwise they stole focus from the hero after loading).
- Recent searches are per account per device (MMKV), not synced to the server.
- Play route keeps `play/[playbackId]` with `playbackId = new`; the playback id is created on that screen.
- `PlayerSession` from the dev lab is reused for the interim player (new `startSeconds`, `diagnostics`).

## Intent
Implement PLAN §5 M4.1 in the M2.4 shells: Home (hero following focus, continue watching, next up,
discover rows), Search (debounced, type filter, per-account recent searches in MMKV), Movie/Series
detail (season picker, episodes with progress, mark played/unplayed), Version picker (sheet/panel,
predicted method from media-caps), play navigation into the M3.1 engine path. Skeleton/empty/error
states, de/en. Verify on Google TV, web desktop + 1024x1366, Android phone against Dev World 39300.
