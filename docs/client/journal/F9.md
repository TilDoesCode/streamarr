## Server request
Both resolved by B9 (`CurrentEpisodeRule`, `available`); the client now follows the server (S1b).
- `SeriesWatchSummaryDto.nextEpisode` (ViewerCatalogService.NextEpisodeAsync) returns the next-up item before any resume
  point, so a replay of a watched episode (B8) is never the series' "next". Prefer the most recent in-progress episode
  (reason "resume") when its lastPlayedAt is newer than the last completion. The client works around it with the
  continue list (`seriesFocus`).
- `/watch/next-up` offers episodes without any version (Sherlock S3E1): filter them or add `versionCount`/`available`
  to `NextUpItemResponse` so Home can mark them without a probe per card.
