## Decisions
- One highlight for the whole backdrop (conservative) instead of per region: the client's crop/layout decides which part
  sits behind the glass, regional values would couple the server to client layouts; can be added later as more fields.
- 95th percentile of the 64 px thumbnail of the w300 rendition (the same image as tint/tint2: backdrop, else poster).
- A palette of an older version keeps serving tint/tint2 with highlight null until recomputed (no colour flash to null).
- Resume `title` is the TMDB title in the viewer's language (movie; series for episodes, matching the client's
  fallback use), the reported title only when TMDB has none. History/state endpoints keep the stored title.
- Unknown VLC codec = not in libVLC's default list after alias normalisation.
- `SpecWarmupService.Lookup` internal init property as a test seam (default: catalog WarmSpecAsync).
