## Decisions
- Library header = one title line (page title left, segmented sort right) + ONE single-line genre row on every form
  factor (`screens/library/genre-row.tsx`): horizontal ScrollView inside the F2 FocusGuide (remember, trap Right,
  destinations = selected chip). The F2 worry (ScrollView swallowing D-pad Left) did not reproduce with the guide: Left
  from All reaches the rail. Focused/selected chips are scrolled inside the gutters (title-safe) by the row itself.
- Edge fade: new `components/ui/edge-fade.tsx` (MaskedView + LinearGradient, like HeroFade) / `.web.tsx` (CSS mask);
  fades only the edge where the row continues (left fade width = start gutter, right = end gutter).
- Phone: the native stack header is off for the Movies/Series roots (Search/Settings keep it); the page draws its own
  title line with a compact sort (caption text, md padding) so title + sort share one line on Android/iOS phones.
- Sort segments are keyed by selected state (`option-on/off`), the GlassChip fix: Android kept a stale square clip when
  only the fill of a rounded view changed. The sort guide's destination is the selected segment (Up lands on it).
- Deep link while the rail has focus: the TV shell hands focus to the opened screen on a pathname change when the rail
  is focused and not in a Back step (`large-shell.tsx`); `useScreenFocusHost` now returns a memoized object.
  A library page that mounts with a genre param (deep link) focuses its selected chip once (`focusChip` initial).
