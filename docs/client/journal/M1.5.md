## Decisions
- TMDB: `ITmdbClient.Strict` (default: the client itself) — `CachingTmdbClient` exposes a view over the same cache and
  single-flight calls that throws `TmdbTransientException` instead of returning the miss fallback. Only viewer catalog
  and age gate use it; resolve/Jellyfin/admin keep the lenient behaviour they were built on.
- Discover answers 503 only when no row is left (partial rows are more useful than an error); restricted lists answer
  503 only when failed certification lookups left nothing.
- Age gate outage → 503 only for restricted viewers; unrestricted viewers never need the rating.
- Gate responses are added by one Swashbuckle operation filter from the endpoint metadata (module gate, viewer
  policy, password-change filter, model-state filter), so new endpoints are covered automatically.
- Nullable `$ref` properties: schema filter using NRT/`Nullable<T>` annotations (`allOf` + `nullable`), not
  `UseAllOfToExtendReferenceSchemas` globally, which would have rewritten every reference in the contract.
- Long-poll on `GET` (`waitMs` 0-10000, wakes on any state change) rather than a blocking `POST`: one mechanism for
  start, switch and repair.
- Full transcodes default to ≤1080p (`transcode_height_default`); a viewer asking for more sets `maxHeight`.
- Tone mapping is declared by the client (`hdrToneMapping`, default true for the assumed libVLC profile); whether
  browsers declare it is a client product decision (M3.1 #5), the server supports both.
- Refresh limit: coalescing per list (join a running search, reuse a list younger than 60 s) instead of a per-viewer
  rate limit — no new state, and it bounds indexer fan-out for any number of viewers.
- CORS: explicit origin list (or `*`), never credentials, only viewer API + `/stream` + `/transcode`.
- `contract_check.py` lives next to `e2e_playback.py` and reuses its helpers so a verifier can rerun it.
