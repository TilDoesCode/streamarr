## Summary
Replay inside the completing playback keeps a resume point again (a report back below the minimum resume percentage
starts a new viewing; reports above it — late, post-credits — of the completing playback stay ignored). Remux audio
groups get one codec per device and title that does not depend on the selected track (fewest conversions, ties to the
lowest source index; the selected track is converted too), so start, `audioLanguage` and `/switch` deliver the same
group; labels are what is delivered (Sintel German AC-3 5.1 -> AC-3 2.0 on 2-ch devices is a real ffmpeg downmix,
5.1 copy on 6-ch devices). Viewer sessions store null instead of "Unknown device" (two migrations: column nullable,
old rows cleared); a display name of only spaces answers 400. B7 leftovers done. HDR10 BBB: file tags and videoRange
are consistent (PQ unless transcoded; e2e guard). Dev World got a fictional long-season series (26 episodes).

## Decisions
- Replay threshold = `MinResumePercent` (5 %): a completing playback's report below it clears `CountedPlaybackId`, so
  the work stays played, later reports set a resume point and reaching the end counts another play.
- Group codec rule: candidates = AAC/AC-3/E-AC-3 targets with an encoder; most copies wins, ties -> lowest source
  index. Chosen over "source default track's codec" because it minimises conversions and is still deterministic.
- Unknown device: store null (not carry the first step's name) — the client sends deviceName on every step and has a
  translated fallback; carrying would need state in the MFA challenge. "Unknown client" stays (not shown to viewers).
- too_many_streams without a device name says "another device" and omits `params.device`.
- Whitespace-only display name -> 400 everywhere CleanDisplayName runs (self-service and admin create/update);
  null/"" still reset to the username.
- HDR10 BBB: no code change needed; `videoRange` = delivered range by contract. Guarded in e2e instead.
- Long season: new fictional series `lighthouse-logs` (tmdbId 990001) instead of extending Pioneer One/Sherlock, so
  existing titles, ids and single-/multi-season client cases stay exactly as they were. No artwork -> not in discover
  rows (a test requires posters there); reachable via search and the Series page. New variant mp4-h264-aac-480p (60 s).
- Dev World `Streamarr:MaxSessions` 256: with > 64 releases the boot test's resolve-all then stream-all evicted the
  first sessions (404).
