## Decisions
- Cooldown answer = 429 with the shared envelope; `ErrorDetail.retryAfterSeconds` (typed, optional) plus
  `params.retryAfterSeconds` (for localized messages) plus `Retry-After`. The hourly cap (5/h) answers the same code
  with the longer wait.
- Sign-in code: an in-memory per-typed-login cooldown (trimmed, case-insensitive, 30 s / 5 per hour, bounded to 10k
  keys) runs before the account lookup, so unknown logins answer exactly like known ones (no enumeration). The DB
  per-account cooldown also answers 429 (only reachable when the same account is addressed by username and e-mail).
- E-mail change: the cooldown is checked before `pendingEmail` changes, so a refused request leaves the pending address
  and the code already sent intact.
- Mail language = the metadata language of the request (`TmdbLanguage.Current` set by the Accept-Language middleware
  from `ViewerLanguages`, else the server `Tmdb:Language`); `de` gets German, everything else English. The admin test
  mail (admin route) uses the server language. `ViewerMailMessage.Language` is recorded (not exposed in the outbox API).
- Display names stay non-unique (username is the unique handle); 1-64 printable chars, `null`/"" resets to the
  username. Absent fields are unchanged (previously `PATCH {}` reset the display name - fixed via presence tracking).
- Avatar keys: cyan, blue, teal, green, amber, coral, rose, slate = the client's colour slots 1-8 in order; `null` =
  derived default. Not added to the admin viewer response (not needed by F4).
- Sign-out-others counts only active sessions (not revoked, refresh not expired); reason `signed_out_by_viewer`.
- `vlcHdrFormats`: absent = default `hdr10,hlg`; `none` or explicitly empty (detected via `Request.Query`) = none;
  `none` mixed with formats = 400.
- Artwork order: posters viewer language -> textless -> English; backdrops textless -> viewer -> English (text sits over
  them); logos unchanged (viewer -> English -> textless). TMDB's default path is kept when it is in the best group.
  Per-language caching already holds (TMDB detail caches key on the language).
- Dev World: TMDB has no German BBB poster, so BBB's German variant is its textless TMDB poster (what the rule picks);
  Sherlock uses the real German TMDB poster (fdu6...). No German logos exist on TMDB for either; logos stay.
- Palette overflow: plain `Queue` under the lock; a new url goes behind any overflowed ones (`Admit`).
- IndexerLanguageTests: the vacuous "no Der/Die in the term" checks replaced by `Term == null` (id-based searches).
