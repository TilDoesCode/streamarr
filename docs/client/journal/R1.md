## Fixes (S1)
1. Lucide icons one by one: `src/components/icons.ts` re-exports the 61 icons in use from `lucide-react-native/icons/<name>`
   (+ types); 50 files import from `@/components/icons`. −1.5 MB minified on web; same saving in the Hermes bundles
   (all icons were in every native bundle too). Jest maps `lucide-react-native/icons/*` to the CJS build (package.json).
2. `src/i18n/polyfills.web.ts`: no @formatjs polyfill on web (every supported browser has Intl.Locale/PluralRules);
   −290 KB. Native keeps the Hermes polyfills.
3. Dev-only routes `/dev/gallery` and `/dev/player` render the not-found screen in release; the screens sit in a dead
   `__DEV__` branch, so Metro's constant folding drops them from release bundles (−97 KB; verified: only the 3-line
   route stub is left in the source map). Settings already hides the developer links behind `__DEV__`.
4. hls.js as its own web chunk: `WebEngine.start` defers an hls.js start until `loadHls()` (cached `import('hls.js')`
   in `src/player/engines/hls-import.ts`) resolved; a newer load or a release drops the deferred source; a failed chunk
   load reports `hlsjs:load`. Safari/native-HLS and progressive starts stay synchronous. −595 KB raw / −181 KB gzip
   from the first load. Jest has no dynamic import (no VM modules), so jest/setup.ts maps `importHls` to `require`.
   Test `src/player/__tests__/web-engine-hls-lazy.test.ts` (deferred start uses the latest source; release drops it);
   mutation: without the stale-source guard the first test fails.
Test: `src/__tests__/release-bundle.test.ts` (barrel guard, icons resolve, no web polyfill, routes with `__DEV__`
false/true). Mutation proof: the guard flags 47 files of HEAD; the HEAD gallery route fails the dev-route test.
Bundle scan after the fixes: no test helpers/mocks of ours (only reanimated's tiny jestUtils), no moment/lodash/date
libs, locales only de/en, no dev-launcher/dev-menu code, LogBox is react-native-web's no-op export.

## Decisions
- Kept every existing colour key (surface, accent, …) with Aurora values instead of renaming, so R2/R3 can migrate
  screens gradually; new groups `aurora` and `glass`. `accent` = `#6FD3E0` (neutral Aurora teal, the no-tint fallback).
- Font family = PostScript name (`Outfit-Bold`, `Figtree-Regular`, `JetBrainsMono-Medium`…); type steps set
  fontFamily and no fontWeight (weights would faux-bold on web). Fonts are local OFL files (not npm deps); full Google
  Fonts files (~390 KB total) instead of a Latin subset (fontTools not installed; small enough).
- No splash hold needed on native: fonts are embedded, so there is no system-font flash; web renders null until
  `useFonts` resolves.
- Glass selection is one pure function (`selectGlassMode`): Reduce Transparency → solid; iOS/tvOS → liquid if
  `isLiquidGlassAvailable() && isGlassEffectAPIAvailable()` else `expo-blur` systemMaterialDark; web → CSS
  backdrop-filter blur 30–40 px + saturate 1.5 + inset top highlight; Android phone → translucent tinted surface
  (no blur); Android TV → solid. Glass never uses overflow hidden (except the iOS < 26 BlurView itself) and is never
  opacity-animated. `@expo/ui` not added (no morphing yet; R3 player cluster).
- expo-blur added (the only new native dependency this round).
- Ambient backdrop: layers keyed by image+tint+tint2, so a tint arriving on refetch crossfades like a focus change;
  it is crossfade-only (no scale), which already satisfies reduced motion. Native uses expo-image `blurRadius` 24 on a
  TMDB `w300` rendition; web uses CSS `filter: blur(70px) saturate(1.5)`.
- Signal bars: local ready 4/ok, downloading 2/info, health ready 4/ok, degraded 2/warn, unknown → no bars.
- Method tones: direct/vlc ok, remux info, transcode warn, unknown neutral.
