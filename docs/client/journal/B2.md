## Decisions
- VLC caps are flat query parameters with a `vlc` prefix mirroring the device ones; per-codec height via `codec:maxHeight`
  because the real Android limit is "HEVC only up to 1080p". Codecs not listed in `vlcVideoCodecs` are not VLC-playable.
  No caps sent → libVLC defaults (unchanged behaviour).
- Container store: LRU by last use, last-use persisted at most every 6 h per entry (no write per list fetch); eviction
  drops the oldest tenth so it does not evict on every insert.
- Keep-data reuses the whole state dir except scratch dirs; seeded viewers are looked up by username, not recreated.
- Probe orphans: Unix cannot make a child die with a SIGKILLed parent portably, so the Dev World script kills the
  instance's descendants on stop and the server kills tracked helpers on ProcessExit.
