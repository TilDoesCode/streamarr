# F10 — The player catches and explains every state

Status: in-progress (S1 + S2 code done 2026-10-05 01:20–01:50, worktree `../streamarr-f10`, branch `round-i/f10`; live checks and S3–S9 follow)

## Intent
Implement the user requirement of 2026-10-05 00:50 (PLAN § 5 "I"): the viewer never sees a generic error, a black
screen or a frozen picture. Every player state is either compensated automatically (wait, reload, new start at the
position, lower quality, step-down, other version) or explained with one specific de/en hint and an action. One
health watchdog per engine (frames, clock, audio), one error taxonomy with a compensation ladder and budgets, jest
tests per matrix row with fake engines, then live runs with Dev World fault injection (B12) on every engine.

F10a (research + design, no devices) is done; F10 S1–S9 are the build slices.

Decisions:
- `categoryOf` lives in `api/` (used by `describeError` on every screen); `classify.ts` builds on it. Unknown code
  without status: name rules (`refresh_*`/`revoked` → T3, `capacity|busy|too_many` → T4, `timeout` → T5,
  `not_allowed|disabled|restricted|forbidden` → T9, `*_not_found|unknown_*|*_closed|*_expired` → T2,
  `unavailable|*_failed|server` → T6, `codec|decod|unsupported|format` → T7), else T11.
- HTTP 503 of the **API** → T4 (busy); 503 of a **media request** → T6 (`segment_unavailable`, matrix C14). 504 → T5.
- Watchdog `slideshow` → T5 (b.1 lists it under T5; § a says T7 — T5 matches its ladder "lower quality"); `starting`
  (no first picture) → T7 per § c "no frames at all → T7".
- An engine error nothing recognises stays T7 `engine_error` (today's step-down behaviour; the ladder is S4).
- `errors.codes.unknown` stays for genuine client exceptions (`toAppError` of a non-AppError); every *server* code the
  client does not know now gets a category text.
- The two B11 refresh codes are not added here (F8 owns them); after the merge they get their own texts and
  `CODE_CATEGORY` entries (T3) — `CODE_CATEGORY` is a `Record<KnownErrorCode, …>`, so tsc fails until they are mapped.
- No player behaviour changed (no ladder, no status UI): only texts, classification and the `status` passed along.
