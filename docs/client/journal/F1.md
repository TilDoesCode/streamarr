## Decisions
- V1: the large shell's content is full width; the rail floats above it. `Design.inset` (rail width, 0 elsewhere) plus
  `gutters()`/`gutterPadding()` give screens a leading gutter that clears the rail while the trailing gutter stays 64 pt,
  so copy and rows keep their pixel positions (hero copy left 168, detail copy 168, rows 168).
- V2: new glass mode `tinted` for Android TV (`selectGlassMode`): smoked base = background mixed with 12 % of the title
  tint at alpha 0.86 (subtle surfaces with only icons/white text: 0.64), 3 % white veil, 1 px top highlight, no blur.
  The worst art behind glass was measured on the emulator (BBB cloud 255,255,221; Sprite Fright neon 219,219,255) and
  `tv-glass.test.ts` asserts white and muted text >= 4.5:1 over both for four tints, incl. the focused version card.
  Version cards on TV lift to glass.DEFAULT (not strong) and the panel's smoked underlay drops to 0.4 there. The TV
  dialog uses the same smoked base (it animates opacity, so it stays a plain view). Reduce Transparency / unknown = solid.
- V3: the version card no longer turns its own border white (FocusLift's ring is the only ring); glow keeps the title
  tint (neutral accent fallback), blur 24. `useFocusGlowRoom()` gives scroll containers room for ring + glow; the version
  panel list and Home shelves add it as padding and pull it back with a negative margin, so nothing moves.
