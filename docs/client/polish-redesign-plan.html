Your decisions (recorded)

„Recommended“ and plain „Play“

The best version that plays without transcoding on this device; transcoding only when nothing else works. Server side in P3, client side in P2.

Web client hosting

Served by the Streamarr server under /watch, same origin, no CORS setup. The web app connects to its own origin without asking for a server URL.

One large-screen shell

Today TV and web look like two different apps: TV has an icon rail and a hero that follows focus; web has a sidebar, a greeting bar, a fixed „top pick“ hero and arrow buttons, and switches to a top bar at tablet size. After the redesign they share one layout; only the input differs.

Shared by TV, web desktop and tablet

Navigation rail with brand mark and profile · hero that follows the focused or hovered title · row and card sizes · section headers · detail layout · version panel · player overlay · motion and transitions

TV

D-pad focus with a strong focus state, remote key map, overscan-safe margins

Web desktop

Pointer hover instead of focus, scroll arrows on rows, keyboard shortcuts, visible focus for keyboard users

Phone

Compact variant of the same components: bottom tabs, stacked hero, sheets instead of panels

Out of scope this round

iPhone, iPad, Apple TV, Liquid Glass (need Xcode) · HDR, Dolby Vision, passthrough, 4K and memory on a 2 GB TV (need real hardware) · offline downloads (next update). All stay in docs/client/BACKLOG.md.
